🚀 놀이공원에서 다양한 운동의 가속도 비교하기

웹 기반 실시간 데이터 수집 및 분석 탐구활동지

🎯 성취기준

[10과탐2-01-01]

영화, 건축, 요리, 스포츠, 미디어 등 생활 속의 과학 원리를 실험 등을 통해 탐구하고, 과학 원리를 활용한 놀이 체험을 통해 과학의 즐거움과 유용성을 느낄 수 있다.

🧰 준비물

  • 아두이노 우노 (Arduino Uno)
  • 3축 가속도 센서 (Adafruit ADXL345)
  • 아두이노 데이터 케이블
  • 소켓 점퍼 케이블

🔌 회로 연결도

5V ➔ VCC
GND ➔ GND
A4 ➔ SDA
A5 ➔ SCL

📝 탐구 진행 순서

  1. 보드 연결: 아두이노를 PC와 연결하고, IDE [툴] 메뉴에서 보드(Uno)와 포트를 선택합니다.
  2. 라이브러리: [스케치]-[라이브러리 관리]에서 Adafruit ADXL345와 Adafruit Unified Sensor를 설치합니다.
  3. 코드 업로드 및 속도 설정: 코드를 보드에 업로드한 후 '시리얼 모니터'를 엽니다. 오른쪽 아래 통신 속도를 반드시 115200 보드레이트로 맞추어 값이 정상적으로 나오는지 확인합니다.
  4. 시리얼 모니터 종료: 값이 잘 나온다면 반드시 시리얼 모니터 창을 닫아주세요. (열려 있으면 웹 보고서와 연결할 수 없습니다.)
  5. 웹 보고서 연결: 우측 상단의 [아두이노 연결하기] 버튼을 누르고 포트를 선택합니다. 5초간 가만히 두어 영점을 잡은 후 측정을 시작합니다.
