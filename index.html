웹 기반 실시간 데이터 수집 및 분석 탐구활동지

🎯 성취기준

[10과탐2-01-01]

영화, 건축, 요리, 스포츠, 미디어 등 생활 속의 과학 원리를 실험 등을 통해 탐구하고, 과학 원리를 활용한 놀이 체험을 통해 과학의 즐거움과 유용성을 느낄 수 있다.

🧰 준비물

  • 아두이노 우노 (Arduino Uno)
  • 3축 가속도 센서 (Adafruit ADXL345)
  • 아두이노 데이터 케이블
  • 소켓 점퍼 케이블

🔌 회로 연결도

5V ➔ VCC
GND ➔ GND
A4 ➔ SDA
A5 ➔ SCL

💻 아두이노 코드

#include <Wire.h> #include <Adafruit_Sensor.h> #include <Adafruit_ADXL345_U.h> Adafruit_ADXL345_Unified accel = Adafruit_ADXL345_Unified(12345); void setup() { Serial.begin(115200); if(!accel.begin()) { Serial.println("No ADXL345"); while(1); } } void loop() { sensors_event_t event; accel.getEvent(&event); Serial.print("X:"); Serial.print(event.acceleration.x); Serial.print(", Y:"); Serial.print(event.acceleration.y); Serial.print(", Z:"); Serial.println(event.acceleration.z); delay(100); }
연결 대기 중

📝 탐구 진행 순서

  1. 왼쪽 아두이노 코드를 복사하여 아두이노 IDE에 붙여넣고 업로드합니다.
  2. 아두이노 IDE의 시리얼 모니터(돋보기 아이콘)를 열어 통신 속도를 115200 보드레이트로 맞춥니다.
  3. 데이터가 잘 나오는 것을 확인했으면, 반드시 시리얼 모니터 창을 닫아주세요. (닫지 않으면 웹과 연결할 수 없습니다.)
  4. 위의 [아두이노 연결하기] 버튼을 누르고 연결된 포트(예: COM3)를 선택합니다.
  5. 영점 조절 (5초): 연결 직후 5초간은 센서를 가만히 두세요. 현재 상태를 기준점(0)으로 자동 설정합니다.
  6. 센서를 움직여 가속도 변화를 관찰하고, 필요시 데이터를 저장합니다.
