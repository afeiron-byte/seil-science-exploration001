웹 기반 실시간 데이터 수집 및 분석 탐구활동지

성취기준

[10과탐2-01-01]

영화, 건축, 요리, 스포츠, 미디어 등 생활 속의 과학 원리를 실험 등을 통해 탐구하고, 과학 원리를 활용한 놀이 체험을 통해 과학의 즐거움과 유용성을 느낄 수 있다.

준비물

  • 아두이노 우노 (Arduino Uno)
  • 3축 가속도 센서 (Adafruit ADXL345)
  • 아두이노 데이터 케이블
  • 소켓 점퍼 케이블

회로 연결도

5V VCC
GND GND
A4 (SDA) SDA
A5 (SCL) SCL

탐구 절차

  1. 회로 연결: 아두이노와 ADXL345 센서를 연결합니다.
    (VCC-5V, GND-GND, SDA-A4, SCL-A5)
  2. 코드 업로드: 하단의 아두이노 코드를 복사하여 아두이노 IDE에서 업로드합니다.
  3. 웹 연결: 우측의 아두이노 연결하기 버튼을 누르고 해당 USB 포트를 선택합니다.
  4. 데이터 수집: 놀이기구 탑승(또는 모형 실험) 중 발생하는 가속도 변화를 실시간 그래프로 관찰합니다.
  5. 결과 저장: 수집이 끝나면 데이터를 CSV 또는 그래프 이미지로 저장하여 보고서에 첨부합니다.

아두이노 소스 코드 

#include <Wire.h>
#include <Adafruit_Sensor.h>
#include <Adafruit_ADXL345_U.h>

/* 라이브러리 설치 필요: Adafruit ADXL345, Adafruit Unified Sensor */

Adafruit_ADXL345_Unified accel = Adafruit_ADXL345_Unified(12345);

void setup() {
  Serial.begin(115200);
  
  if(!accel.begin()) {
    Serial.println("ADXL345 센서를 찾을 수 없습니다.");
    while(1);
  }
  
  // 측정 범위 설정 (+- 16G)
  accel.setRange(ADXL345_RANGE_16_G);
}

void loop() {
  sensors_event_t event; 
  accel.getEvent(&event);
  
  // X, Y, Z 가속도 데이터를 콤마로 구분하여 웹으로 전송 (단위: m/s^2)
  Serial.print(event.acceleration.x); Serial.print(",");
  Serial.print(event.acceleration.y); Serial.print(",");
  Serial.println(event.acceleration.z);
  
  delay(50); // 약 20Hz 속도로 데이터 전송
}
